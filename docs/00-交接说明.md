## 文件与阅读顺序

1. **01-产品与开发规格.md**：正式版本的页面、功能、视觉参数、技术架构、内容模型及部署要求。
2. **02-设计复核与验收.md**：实际检查发现的问题、保留项、调整项，以及逐项验收方法。
3. **03-给开发AI的任务书.md**：可直接使用的开发任务说明。
4. **prototype/**：用户认可的可运行视觉参考。进入目录执行 `node serve.cjs`，浏览器打开 `http://127.0.0.1:4327`；也可直接打开 `index.html`。

原型服务器若提示端口被占用，先确认是否已有这份原型在运行；不要结束不明进程。正式开发使用自己的开发服务器。

## 文档与原型如何配合

- 原型是视觉基线：品牌、颜色、版式气质、图形语言均应继承。
- 开发规格描述正式版本；设计复核解释哪些原型细节必须调整。
- 原型是静态 HTML，不是已完成的 Astro 项目，不包含搜索、RSS、内容系统或部署流程。
- 原型的文章和选题是草稿，不可直接当作韩飞已发表的成果。
- 原型内 `DESIGN.md` 是历史说明；如与本交接文档冲突，以本交接文档为准。
- 本次仅输出交接文档和原型副本，没有实施复核中提出的全部调整，没有创建或发布 GitHub 仓库。
